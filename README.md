# Homebrew tap for ST Reborn

```
brew install --cask jrpersonal/tap/st-reborn
```

ST Reborn (STR) brings Bose SoundTouch speakers back after the Bose cloud shutdown. Project: https://github.com/JRpersonal/streborn, website: https://st-reborn.de

The cask is updated automatically by the STR release workflow.
